One deadpan line: an AI agent blames its own context window for missing a deadline — it evicted the deadline, hallucinated a calmer one, and filed it under done.

## Run it

```sh
python3 main.py
```

This writes the single excuse line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
